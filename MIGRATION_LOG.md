## 🔄 Status Definitions

- **🔴 Not started** — legacy file exists, not yet touched
- **🟡 Sourcing** — verifying canonical source (Phase 1)
- **🟠 Authoring** — building word-stacks (Phase 2)
- **🟢 Published** — `.md` complete, index.html updated, render-verified
- **⚫ Archived** — legacy `.html` moved to `/legacy/` folder
- **⛔ Skipped** — content deemed not appropriate to migrate (e.g., fabricated, contested without safer alternative)
